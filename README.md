# palomagtzr.github.io

Personal portfolio of Paloma Gutiérrez Ricaud. Astro + Tailwind CSS + GSAP + Lenis, deployed to GitHub Pages with GitHub Actions.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

Source assets live in `portfolio-assets/`; optimized copies are in `src/assets/` and `public/`.
